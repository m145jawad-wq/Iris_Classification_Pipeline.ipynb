# Multi-Class Benchmark Classification Pipeline

## Project Overview
This project implements a multi-class classification pipeline using the Iris dataset and Python. It compares Logistic Regression and Decision Tree models using Scikit-Learn.

## Objectives
- Load and explore the Iris dataset using Pandas.
- Visualize features using a Seaborn pairplot.
- Split the dataset into 80% training and 20% testing data.
- Apply StandardScaler to Logistic Regression.
- Train Logistic Regression and Decision Tree models.
- Evaluate accuracy, precision, recall, and F1-score.
- Visualize confusion matrices using heatmaps.
- Compare model performance using a bar chart.
- Visualize decision boundaries using two Iris features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Installation
Install the required libraries by running:

pip install pandas numpy matplotlib seaborn scikit-learn

## How to Run
Run the Python file using:

python iris_classification.py

## Output
The program displays evaluation metrics and generates graphs for the pairplot, confusion matrices, model comparison, and decision boundaries. It also saves the graphs and metrics in the output folder.

## Dataset
The Iris dataset contains three flower classes: Setosa, Versicolor, and Virginica.

## Models
1. Logistic Regression
2. Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Macro Precision
- Macro Recall
- Macro F1-score
